data/repositories/ — API 호출 인터페이스 + Mock 구현체
----------------------------------------------------------------

각 파일에 abstract class XxxRepository(인터페이스)와
MockXxxRepository(목 데이터) 두 가지가 함께 존재.

현재는 Mock 구현체를 사용 중이며,
API 연동 시 HttpXxxRepository 로 교체할 구조.

================================================================
백엔드 개발자에게 특히 전달할 점
================================================================

1. Repository 패턴 사용
   현재 모든 API 호출부는 MockXxxRepository 로 대체되어 있음.
   실제 서버 연동 시 HttpXxxRepository 를 같은 인터페이스로
   구현해서 주입하면 됨. UI 코드 수정 불필요.

2. 토큰 관리
   accessToken / refreshToken 모두 기기 보안 저장소에 보관.
   인터셉터로 자동 갱신 구조 예정 (현재 미구현).

3. 두 서버 분리
   SpringBoot  → api_constants.dart 의 springBaseUrl  → 대부분의 API
   FastAPI     → api_constants.dart 의 fastapiBaseUrl  → 브리핑·AI 요약 전용

4. API 명세 typo 대응
   estimateDuration / estimatedDuration 혼용을 모델에서
   null 합체 연산자(??)로 양쪽 파싱 처리해둠.

5. userId 타입
   userId 는 int (Long) 타입. String 아님.
